Why Password Security Matters

Passwords are one of the most important methods of protecting online accounts and personal information.

Characteristics of a Strong Password

  • Use a long password or passphrase.
  • Use a combination of letters, numbers and symbols.
  • Avoid names and easily guessed information.
  • Never reuse the same password everywhere.
  • Use a password manager when appropriate.
  • Enable multi-factor authentication.

❌ Avoid These

❌ Using your name as a password

❌ Using your date of birth

❌ Using simple passwords like "123456"

❌ Sharing passwords with others

❌ Reusing passwords across multiple accounts

Strong Password + MFA = Better Account Protection
